# 📖 About

This project extracts printed text from an image using **Optical Character Recognition (OCR)** with **Tesseract OCR** and **OpenCV**.

It demonstrates a basic OCR pipeline including image loading, preprocessing and text extraction.

---

# ✨ Features

- 📷 Read image from dataset
- 🔍 Image preprocessing
- 📝 Text extraction using OCR
- ⚡ Fast and lightweight
- 🐍 Written in Python
