# 🧠 AI Career Recommendation System

An AI-based Career Recommendation System built using **Python**, **Pandas**, **Scikit-learn**, **TF-IDF Vectorization**, and **Cosine Similarity**.

The application recommends the **Top 3 career paths** based on the technical skills entered by the user.

---

## 📌 Features

- Accepts multiple technical skills
- Minimum 3 skills validation
- Duplicate skill detection
- TF-IDF Vectorization
- Cosine Similarity
- Top 3 Career Recommendations
- Match Score Percentage
- Best Career Recommendation
- Clean command-line interface
